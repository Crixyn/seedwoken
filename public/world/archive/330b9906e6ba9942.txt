VISUAL ASSET INDEX — CRIXYNCO


Purpose
This index governs the curated visual archive. It records which visual families belong in the master library and how to decide which version is authoritative.


Core Selection Rule
Keep the strongest current or final approved version of a visual concept. If later edits were made because an earlier version was disliked, inaccurate, unfinished, overly grainy, poorly composed, visually broken, or otherwise superseded, the later successful correction should replace the earlier version in the curated archive.


When Multiple Versions Are Allowed
Keep more than one image only when the versions serve genuinely different purposes: separate panels in a series, distinct stages in an instructional progression, alternate aspect ratios needed for publishing, intentionally different compositions, or client-requested variants that remain useful.

Temporary holding area for visuals whose final status is unclear. Nothing here should be treated as authoritative until reviewed.

The Land Remembers / Missoula Floods — preserve the intended series panels and strongest supporting factual visuals; reject weaker redundant attempts.
Deep-sea / wildlife work — retain distinct finished compositions and useful infographics rather than near-identical experiments.
Garden and plant work — retain useful final educational or publishing assets; reject redundant generated variations.
Client work — preserve final deliverables and only those process screenshots that document a still-relevant workflow.


Naming Standard
Where practical, use descriptive filenames that identify the subject and purpose. Generic camera names or generation timestamps should be renamed only when the visual has been positively identified.


Archive Standard
The curated library is a working master asset collection, not a complete history. The original source Library can preserve historical iterations separately. Do not clutter the curated Drive library with rejected drafts simply because they exist.
