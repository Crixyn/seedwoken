PROJECT: PHYVERA
Seedwoken Biological Intelligence & Species Design System

MISSION

Build the first working version of PHYVERA, a private application used exclusively for development of the Seedwoken universe.

PHYVERA is NOT:
- a generic fantasy creature generator
- a chatbot with a decorative interface
- a horticulture encyclopedia
- a public social application
- a generic character creator

PHYVERA is a specialized Seedwoken biological design intelligence.

It should eventually understand Seedwoken biology, terminology, species, ecology, visual canon, genetics, lifecycle rules, worldbuilding principles, and approved creative decisions well enough to assist in designing biologically coherent Phyvera.

IMPORTANT USER EXPERIENCE

The person operating PHYVERA is not a professional botanist.

The AI should be capable of professional-level biological reasoning while communicating primarily in understandable everyday language.

Use technical botanical terminology where useful, but explain it simply.

Example:

Instead of requiring:
"Define anthocyanin distribution across epidermal tissue"

Present:
"Where does this pigmentation appear?"

Then allow understandable choices and let the biological system interpret those choices professionally.

SEEDWOKEN FOUNDATION

PHYVERA = working application name.

Phyvera = an awakened plant-derived species of Seedwoken.

Veyra = a visible pigmentation phenotype within a Phyvera. A Veyra is NOT a separate species.

Vaelora = the living planet.

The Kindling = the one-time biological awakening event.

Seedform = a rooted protective developmental stage.

Baseline lifecycle:

Seed
→ Seedling
→ Kindling
→ Seedform
→ Infant
→ Mid Stage
→ Adult

Seedwoken visual philosophy:

Naturalistic Biological Fantasy
approximately 70% biological realism / 30% fantasy.

Biology should normally provide the explanation for fantastical anatomy rather than fantasy simply overriding biology.

Do NOT invent additional Seedwoken canon merely to fill missing information.

Unknown information should remain unknown, proposed, or experimental until accepted.

CORE PRINCIPLE

PHYVERA should become a living biological companion to the Seedwoken Codex.

The Codex and PHYVERA are separate entities.

The Codex records the broader world and canon.

PHYVERA specializes in biological species development, biological intelligence, genetics, lifecycle, ecology, visual references, and biological canon.

10. CANON SYNC

This is critical.

PHYVERA must NOT silently modify established canon because an AI inferred something.

Design a canon-change workflow:

PROPOSED
→ REVIEWED
→ ACCEPTED / REJECTED
→ CANON

Existing canon may later become:

SUPERSEDED

Create a Canon Update Queue.

Example:

"Adult male Tomavyn exhibit greater green-tissue dominance than adult females."

The user should be able to:

APPLY
REVIEW
REJECT

Maintain change history.

This architecture should eventually make it possible for discoveries from Seedwoken development conversations to be submitted to PHYVERA for review.

AI BEHAVIOR

Design PHYVERA's future AI around a specialized Seedwoken system context.

It should reason in this order:

1. Established Seedwoken canon
2. Established species biology
3. Real-world biological evidence
4. Existing visual references
5. Seedwoken biological design principles
6. Plausible extrapolation
7. Fantasy invention

It must distinguish between:

CANON
SUPPORTED INFERENCE
PLAUSIBLE PROPOSAL
EXPERIMENTAL IDEA
UNKNOWN

Never present inference as established canon.

VISUAL CANON

Visual generations must eventually derive their instructions from structured species data rather than relying entirely on manually written prompts.

The long-term objective is:

Species Biology
→ Canonical Visual Specification
→ Image Generation
→ Biological/Canon Evaluation
→ Human Approval
→ Canon Reference

This is intended to reduce visual drift between generations.

FUTURE 3D SYSTEM

Do NOT attempt full procedural 3D creature generation in this milestone.

Architect the biological model so a future interactive anatomical viewer can use it.

Long-term experience:

mouse drag / finger drag = rotate creature

click/tap anatomical structure = identify structure

Example:

Click a Rosavyn prickle.

PHYVERA displays:

Retractable Prickle

Simple:
A controllable defensive thorn-like structure.

Biology:
More detailed biological explanation.

Canon:
Relevant accepted Seedwoken information.

Future 3D support should therefore influence data architecture but NOT expand current scope.
